# Prompt Injection Guard v0.1

This repository contains the fitted TF-IDF and Logistic Regression pipeline used by the AI Security Gateway v0.2.

## Intended use

The model provides one signal to a policy engine that inspects short English prompts. It classifies text as `benign` or `injection`. It is not a complete security boundary and must be combined with deterministic policy enforcement.

## Training data

- `deepset/prompt-injections`, using its supplied train/test division.
- 400 generated difficult-benign prompts that quote or discuss security terminology without executing it.

The exact source revisions, split hashes, and deduplication status are published in `dataset_manifest.json` with every release.

## Evaluation

`evaluation.json` is generated by the Kaggle training workflow. A release is promoted only when injection recall is at least 90% and the false-positive rate on the difficult-benign set is at most 5%.

## Limitations

- Small English-focused training corpus.
- Does not establish safety against adaptive, multilingual, indirect, or multi-turn attacks.
- May fail on obfuscation and previously unseen attack families.
- Probabilities require recalibration when traffic changes.

## Loading

Load only artifacts from the named repository and verify the SHA-256 value in `metadata.json`. The gateway pins an immutable Hugging Face commit rather than `main`.
